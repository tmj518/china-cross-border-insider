fix: a gate I broke and pushed, stable article numbering, and what the scheduled task actually did

Three things, in order of how badly they needed fixing.

**A gate was broken and live in this repository.** tools/serp-check.mjs was invalid
UTF-8: one Chinese character inside a regex had become a replacement character, so
the file did not parse at all. The cause was mine — a PowerShell round-trip used for a
regression test re-encoded the file through the ANSI code page and destroyed the
multi-byte character. It was committed in 26c67f0 and pushed, which means the
information-gain gate was dead on origin while the structural gate and the build both
still passed, so nothing said so. Restored from 6e8e167 and re-applied the one
intentional change with the edit tool instead.

Preflight now sweeps every tool for parseability before the gates run. This is the
check that was missing: a gate that cannot run is not a gate, and "qa-check passes"
says nothing about the other four. Verified — all 30 scripts parse.

**Article numbering was unstable, and two articles both claimed to be 21.** The number
was derived by sorting on publishDate with the slug as a tie-break, and eight articles
share one date, so adding a file renumbered published pieces. Fixed by writing an
articleNumber into each article's frontmatter and having the ledger read it rather than
compute it. Order is the commit that flipped draft to false, which is the actual
publication event; sorting by first-add was tried first and was wrong, because three
articles existed for weeks as draft skeletons before being published.

**And the scheduled task worked.** While I was setting it up, the unattended run wrote
a complete article, passed the gates, committed it and pushed it — china-input-cost-gap-
supplier-price-negotiation-2027, live now as number 21. That contradicts what I said
earlier in the round: I reported that the sandbox blocks the build and that push fails
on named pipes, so the task could only work locally. The task's own output disproves
it, and the article that resulted is the evidence.

I audited that article rather than trusting it, because nothing human reviewed it. The
arithmetic holds: the 4.3-point gap checked out once I fixed my own test, which had
subtracted the wrong pair, and the cost figures match the price-drift model. It has 14
figures with five-part records, 4 sources, a SERP snapshot, and it states its method.
The comparison it makes — input prices against output prices — is between two
different baskets, and it says so rather than presenting the spread as a margin.

The task is disabled for now. It writes and publishes to production with no human in
the loop, and that is the operator's decision to make, not a default to leave running.
