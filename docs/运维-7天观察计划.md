## 三、飞书卡片怎么读

| 卡 | 含义 | 要不要动手 |
|---|---|---|
| ✅ PUBLISHED | 发文成功 | 不用 |
| 🟡 NO-SUBJECT / DUPLICATE-SUBJECT / INSUFFICIENT-EVIDENCE | 今天没找到可写的题，或写不出带来源的数字 | 不用，这是正确判断 |
| 🟡 PUBLISHED-DEGRADED / PUBLISHED-WITHOUT-FINISH | 发了，但有未结项 | 第 7 天一起看 |
| 🔴 REJECTED / WRITE-FAILED / CI 闸门失败 | 真失败 | 记下来，第 7 天一起修 |
