**★ 三条线是三种不同的假设，不是三个备份。这一点必须先对齐，否则会误判谁是冗余。**

| 线 | 理论 | 假设 | 当前状态 |

| **A** script | **稳** | 每天必须有一篇能发出去 | 07:20/09:20 运行；今天 `DUPLICATE-SUBJECT`（护栏生效） |
| **B** agent | **探** | 智能体能找到流水线想不到的题材 | 持续 `PUBLISHED-WITHOUT-FINISH`，**0 次自主完成** |

**★ 重要判断：三条线都不能停。**
**B 线的问题不是"该不该存在"，而是"它的探索产出没有出口"（见第十五节）。**

## 十九、需求侧诊断（最重要的发现）

**★ 现状：90 天 27 个查询、9 次点击。**

**★ 报告里的判断是"这不是质量问题，是没人搜"。我部分同意，但要补一条可能被忽略的解释：**

```
GSC 只测 Google。
而目标买家（进口商、清关行、跨境卖家）越来越在 AI 引擎里问：
  "what is the import duty on X into Germany from China"
★ 这些问题不会出现在 GSC 里
★ 证据：GA4 里那 1 次 AI Assistant 会话 —— 有人从答案引擎点进来了
```

**★ 所以"没人搜"可能只在 Google 里成立。三条解法，按成本排序：**

| 解法 | 成本 | 说明 |
|---|---|---|
| **AI 引擎引用探测（AEO 反向工程）** | 近 0 | 30 个真实买家问句丢给 ChatGPT/Perplexity/Gemini，看是否引用本站；没被引用的就是要写的题 |
| **长尾扩张** | 近 0 | GSC 27 个 query 的变体 + PAA 问句 + Bing 免费 keyword API → 200+ 带意图标注 |
| **热搜/趋势（按国）** | 近 0 | Google Trends 只拉 GA4 里真实出现的国家（SG/MY/DE/NL/JP）的 rising queries |
| 付费三方（Ahrefs/Semrush） | 高 | **建议先不买** —— 缺的不是量级，是"哪些问题值得回答" |
