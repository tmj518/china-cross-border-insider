# 运营指令：A 线的产能与题材（2026-11-09，总监口述，执行者记录）

> 本文件是 `docs/初心与目标.md` 第〇节之下的**执行层指令**。与初心冲突时以初心为准；
> 初心没有规定、由总监在这里裁定的，以本文件为准。**云端必须能按这几条自己判。**

---

## 一、初心（照抄，防走样）

> **把中国翻译成外国人的钱包。**
>
> 外国人和中国打交道，只有五个时刻：**买、来、住、走、政策分析**。

最关键的一句：**政策分析是原材料层，外国人真正需要解决的是具体问题。**
用户不会因为一篇政策分析付费；他会因为"一批货进口到美国花多少钱""我能不能免签入境""在中国租房有哪些实际费用"而使用产品。

**所以真正的产品是：以英文服务外国人的中国办事与成本决策平台。**

四层指标里，①系统可靠性是基础，②③④才决定项目是否值得继续：需求覆盖、流量与使用、商业验证。
**"今天又发了几篇"不算业务成功。**

## 二、总监 2026-11-09 的裁定（A 线产能）

### 2.1 现状被否掉的那一条

```
被否    "A 线只写有可验证数字的分析稿 → 一周 2-4 篇"
理由    太少。初心要的是"外国人真正需要解决的具体问题"，不是"能被五段数字支持的政策稿"
```

### 2.2 三条命令

| # | 命令 | 落地状态 |
|---|---|---|
| 1 | **扩大信息源** | 27 → **50** 个；新闻线（新华社英文/中国日报/环球时报/人民网）**每轮优先**；文章按 URL 日期倒序，日志打 `fresh: N article(s) dated today` |
| 2 | **降低审核标准** | 审稿意见**只记录不拦发布**（PUBLISHED-DEGRADED）；`figure trace` 闸门降为**只报不拦**；复审日期过期由"必须红"降为**警告** |
| 3 | **拓展题目类型** | 允许**无数字文章**（正文不含金额/百分比 → `figures: []` 合法）；新闻头条进入选题池，优先级高于矩阵 |

### 2.3 题材边界（总监原话）

> **只要外国人喜欢看的、喜欢看中国的信息，我们都发布。**
> A 线很多可以介绍中国的呢。不要太死板了。
> 谷歌分析和谷歌蓝海词有搜索量 —— 说明有人喜欢，我们就搞。

**因此 A 线可以写：**

- 中国政策与措施（原有）
- 中国产业、展会、口岸、城市变化（新增）
- 外国人在中国会遇到的规则、手续、费用（原有，初心四时刻）
- 有搜索量、但拿不到精确数字的主题 → **写解读，不写数字**

**仍然不许：**

- 编数字（无来源的金额、百分比一律不许出现）
- 把违规写成省钱手段
- 同一事件发第二篇

## 三、云端必须能自己判的四条（执行层核对表）

```
① 有今天的新闻吗      data/news/<date>.json 里的 items 数量 > 0
② 今天有稿吗          data/runs/ 里今天有 PUBLISHED；没有 → 兜底跑 C 线
③ 这篇有数字吗        正文出现金额/百分比 → 必须有 figures 记录；没有 → 只许写解读
④ 撞重复了吗          产品词 Jaccard ≥ 0.5 → 拒绝，判 DUPLICATE-SUBJECT（黄卡，不报错）
```

---

## 四、验收标准（不达标就改，不改初心）

| 指标 | 目标 | 怎么看 |
|---|---|---|
| 每天有稿 | **100%** | 台账里每天至少一条 PUBLISHED（A/B/C/兜底都算） |
| A 线周产出 | **≥ 5 篇**（原 2-4 被否） | 运行台账 route=script 的 PUBLISHED 计数 |
| 新闻利用率 | 每天抓到的头条 > 0 且进入选题池 | C 线日志的 headline 行 + 队列新增 |
| 无数字文章占比 | 允许存在，但每篇不许含数字 | `figure trace` 软闸门报告 |

**★ 达不到就动机制，不动初心。**
