## 五、DoD（项目结束条件）

每条线，连续 N 个班次同时满足：
1. run 出现在**班次 ±3 分钟内**（自动派发），不是手动补跑；
2. `conclusion = success`——不是"文章发了但 run 红"；
3. verdict 合格且文章 200 + sitemap；
4. 该班次期间**没有人工补跑**（补跑即判该班次失败）。

N：A = 3 天（两班都算）、C = 3 天、B = 2 个班次（周日/二/四）。
今晚修完 → D1 = 11-11；A/C 最早 11-13 收口，B 最早 11-15；**目标 11-16，硬上限 11-17**。
到 11-17 还不达标 → PM 出降级方案交用户拍板，不由执行自行放宽。
