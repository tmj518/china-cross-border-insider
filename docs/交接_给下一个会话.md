## 五、三件会骗你的事（我都上过当）

### 1. 本地 `dist` 是陈旧的 → 假 PASS

```
我用本地 dist（213 页）跑闸门 → PASS
CI 用全新构建（217 页）→ FAIL
★ 差的那 4 页里，就藏着撞名的那一页
★ 纪律：验证前先【全量重建】，页数要和 CI 对得上再信结论
```

### 2. 模式不全的扫描，零命中是假阴性

```
我说过"未发现凭据泄露" —— 错了
因为我的正则只有 sk- / ghp_ / BEGIN PRIVATE KEY
完全没有飞书形态（cli_ / bascn / wiki token）
★ 纪律：零命中不能证明"没有"，只能证明"这个模式没匹配到"
```

### 3. 按配置算出来的日志，不是事实

```
卡片上写 "volces 写 / deepseek 审"，那是 providerFor() 的返回值，是"打算用谁"
账本证明：三条线的模型工作事实全部落在 DeepSeek
★ 纪律：事实只能来自调用账本，不能来自配置、不能来自计划
```
